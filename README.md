# worthit.
WorthIt? 🍕🔥 Search a dish, see its calories, and find out how much walking, cycling or squats it takes to burn it off. Finish the challenge to unlock your meal. A clickable HTML/JS prototype.
WorthIt?

Is that biryani worth it? Find out before you bite.

WorthIt? is a playful calorie app concept. Search a dish and it tells you, in exercise terms, what that meal really costs. Calorie counts are abstract, but “45 minutes of cycling” isn’t.

This repo is a clickable prototype: one self-contained HTML file with no build step and no dependencies.

The journey
Search: one bold search bar with live suggestions.
Dish card: a big calorie number, serving size and a smart swap tip (“swap naan for roti, save ~250 cal”).
Pick your burn: brisk walk, cycling, running, weights, squats + walk, or pushups + walk. Times are calculated from your body weight.
Challenge: a live progress ring with tracking for each exercise. The demo runs at 1 second = 1 minute.
Unlocked: finish the challenge to unlock your meal and build a daily streak.

You can also choose “Eat now, burn later”. The calories are saved as a debt you can burn off afterwards.

Features
14 dishes to start with, mostly Indian (dosa, biryani, vada pav, chole bhature and more)
Burn estimates based on standard MET exercise values, adjusted to your weight
Streaks and owed calories saved in your browser’s local storage
Mobile-first, clean UI
Run it

Open index.html in any browser, or turn on GitHub Pages for this repo.
